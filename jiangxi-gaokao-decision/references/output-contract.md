# 输出契约

每次正式建议按以下结构输出：

1. **数据状态**：本次使用年份、最后更新日期、缺失和过期模块。
2. **硬门槛结果**：预算、地域、办学性质、选科、体检和调剂底线。
3. **三条社会入口**：公家、公司、创业分别说明进入条件和现实概率。
4. **分项矩阵**：学校资源、身份覆盖、江西需求、产业兑现、AI韧性、
   执行匹配分别评价，不合并成万能总分。
5. **路径组合**：主路径、备选路径、保底路径。
6. **四年行动**：每条路径列出课程、证书、实习、考试和退出条件。
7. **失败退路**：考研、考公或就业未达成时的次优路径。
8. **证据链**：关键判断使用“结论 → 数据 → 原始来源 → 推理过程 →
   不确定性 → 失败退路”的格式。

没有足够官方证据时明确写“证据不足”，不凭热门度、媒体声量或个人印象补齐。
