# 数据与证据模型

## 六层架构

1. 原始证据层：网页、PDF、表格原件和内容哈希。
2. 关系数据层：录取、专业组、岗位、产业项目和AI任务信号。
3. 文本检索层：政策、章程、招聘公告和报告的分块检索。
4. 证据审查层：来源级别、适用年份、时效、冲突和缺口。
5. 决策引擎层：硬门槛与六项独立评价。
6. 个案记忆层：考生条件、选择变化、执行结果和复盘。

## 来源等级

- `official`：考试院、政府、高校、招聘单位原文，可支撑关键事实。
- `primary_research`：原始研究机构，可支撑AI任务与劳动力趋势。
- `third_party`：只用于发现线索，关键结论必须回到原文核验。

## 关键原则

- 快照按内容哈希去重，来源变更时保留历史版本。
- 每项证据关联快照，快照关联来源和原始文件。
- 政策方向不自动等于岗位需求。产业结论至少区分政策、投资、
  企业落地和本科岗位四个层次。
- AI分析以工作任务为粒度，不给整个专业贴“消失”标签。
- 首版使用 SQLite FTS/文本包含检索。未来可增加向量索引，但结果仍须
  返回 `snapshot_id`，不得形成无法追溯的独立知识库。
